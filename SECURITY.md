# Security Policy

## Reporting

Please report suspected security issues privately through the repository security channel or by contacting the maintainer before public disclosure.

## What to include

- affected version
- reproduction steps
- impact summary
- Home Assistant version and environment details

## Scope notes

PilotSuite HA runs inside Home Assistant as a custom integration. Please include whether the issue affects:
- config flow
- secrets or token handling
- webhook or HTTP surfaces
- packaged release artifacts
