# PilotSuite — Home Assistant Integration

**PilotSuite HA** ist die Home Assistant Integration für PilotSuite Core.

## Voraussetzungen

- Home Assistant >= 2024.4.0
- [PilotSuite Core Add-on](https://github.com/GreenhillEfka/pilotsuite-styx-core) (erforderlich)

## Installation

### Option 1: HACS (Empfohlen)

1. HACS → Integrationen → Explore & Download Repositories
2. Nach "PilotSuite" suchen → Installieren

### Option 2: Manuell

1. `custom_components/` in `config/custom_components/` kopieren
2. HA neustarten
