## 4. Performance-Issues: CacheManager + Zone Engine 🟡

### CacheManager (`api/cache_manager.py`)

#### Issues Found

1. **Kein Async-Support** ⚠️
   - Alle Methoden sind synchron (`def get`, `def set`)
   - Flask-App blockiert bei Redis-Operations
   - **Fix:** `async def get/set` + `aioredis` statt `redis`

2. **Inefficient Eviction Strategy** ⚠️
   - `_evict_oldest()` scannt alle Keys für Minimum
   - O(n) complexity bei vollem Cache
   - **Fix:** LRU mit `OrderedDict` oder Redis-native eviction

3. **No Connection Pooling** ⚠️
   - Redis client wird einmalig erstellt, kein Pool
   - Bei hoher Last: Connection exhaustion
   - **Fix:** `redis.ConnectionPool` im `__init__`

4. **Pickle Security Risk** 🔴
   - `pickle.dumps/loads` für Kompression
   - **Risk:** Arbitrary code execution via malicious pickle
   - **Fix:** `json.dumps/loads` + `gzip.compress`

```python
# Current (risky)
return pickle.dumps(data)

# Recommended
import gzip, json
return gzip.compress(json.dumps(data).encode())
```

### ZoneMatcher (`homeassistant/zone_matcher.py`)

#### Issues Found

1. **Inefficient String Similarity** ⚠️
   - `_string_similarity()` ist O(n*m) ohne Caching
   - Wird für jedes Keyword bei jedem Match aufgerufen
   - **Fix:** Levenshtein-Distanz mit Caching (functools.lru_cache)

2. **No Batch Processing** ⚠️
   - `match_multiple_rooms()` callt `match_room_to_zone()` n-mal
   - Keine Parallelisierung möglich
   - **Fix:** `asyncio.gather()` für batch matching

3. **Memory: Fuzzy-Mappings Hardcoded** ℹ️
   - 20+ fuzzy mappings im `__init__`
   - Bei 1000+ Rooms: Memory overhead
   - **Fix:** Externe Config-Datei oder Database

4. **Review-Queue Unbounded** ⚠️
   - `get_review_queue()` gibt alle low-confidence Matches zurück
   - Bei 1000 Rooms: Queue explosion
   - **Fix:** Pagination oder Limit (max 100 items)

|-----------|-------|--------|

| ZoneMatcher | 7/10 | String similarity, no batching |
