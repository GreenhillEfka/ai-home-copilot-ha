| Location | Version | Erwartet |

| Git Tag | v11.3.0 | ✅ 11.3.0 |
| `VERSION` Datei | 11.2.0 | ❌ 11.3.0 |
| `config.yaml` | 11.2.1 | ❌ 11.3.0 |

**Problem**: Der Release-Tag v11.3.0 wurde erstellt, OHNE die VERSION-Dateien zu aktualisieren!

**Folgen**:
- `production-guard.yml` wird fehlschlagen (prüft Tag-Existenz für VERSION)
- `addon-validate.yml` wird fehlschlagen (Version Mismatch zwischen config.yaml und VERSION)
- Add-on Build wird inkonsistente Versionen haben

**Fix erforderlich**:
```bash
# VERSION Datei aktualisieren
echo "11.3.0" > copilot_core/rootfs/usr/src/app/VERSION

# config.yaml aktualisieren
# version: "11.3.0" in copilot_core/config.yaml setzen

# Commit & Tag korrigieren
git add copilot_core/rootfs/usr/src/app/VERSION copilot_core/config.yaml
git commit -m "chore: bump VERSION to 11.3.0 for release"
git tag -d v11.3.0
git tag v11.3.0
git push --tags --force
```
