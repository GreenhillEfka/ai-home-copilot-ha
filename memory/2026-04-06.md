## 🗣️ HA SPRACHBEFEHL-ROUTER (Slice 163) — DESIGN

**Goal:** Enhance HA Conversation Agent to route voice commands intelligently between:
1. Local LLM (Ollama) for simple commands
2. Cloud LLM for complex reasoning
3. Direct HA service calls for known intents
4. RAG-enhanced responses with home context

**Architecture:**
```
User Voice → HA Conversation Agent
    ↓
Intent Detection (regex + ML classifier)
    ↓
┌─────────────────────────────────────┐
│  Router Decision                    │
│  - "licht an" → HA service call     │
│  - "wie wird das wetter" → RAG+LLM  │
│  - "plane eine party" → Cloud LLM   │
└─────────────────────────────────────┘
    ↓
Response Generation → TTS (optional)
```

**Intent Categories:**
- `home_control` → Direct HA service (lights, climate, covers)
- `query` → RAG lookup + LLM synthesis
- `complex_task` → Cloud LLM with tool calling
- `fallback` → Local LLM
