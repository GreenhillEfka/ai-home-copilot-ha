**Released:** 2026-04-07

- Notifications (Pushover, Telegram)
- Calendar integrations
- Weather automations
- Scene management
- Plugin system
- Multi-home sync
- Analytics & reporting
- Contract system
- Plugin Hub marketplace
- Full deployment options (HACS, Docker, systemd)
