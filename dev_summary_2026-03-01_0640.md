### DeprecationWarnings Bereinigung

**Problem:** `datetime.utcnow()` ist in Python 3.12+ deprecated  
**Lösung:** Ersetzt durch `datetime.now(UTC)` für timezone-aware datetime objects

**Betroffene Dateien:**

| Datei | Änderungen | Zeilen |

| `tests/test_unifi.py` | Roaming storm test | 1 |

**Insgesamt:** 9 Vorkommen von `datetime.utcnow()` ersetzt

### Code Changes Details

#### 1. Import-Updates
